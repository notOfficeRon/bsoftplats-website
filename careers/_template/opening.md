# HOW TO ADD A JOB
#
# 1. Duplicate this folder (careers/_template).
# 2. Rename the copy. Do not start the name with _ .
#    example: product-owner
# 3. Keep the file name opening.md
# 4. Fill in the fields. title is what the applicant sees and what Apply sends.
# 5. Bullet lines must start with "- ".
# 6. Delete the folder to take the job down.
# 7. Commit and push main. It shows on /careers.
#
# description: one paragraph on the same line, or leave it empty and write
# paragraphs on the following lines until Responsibilities.
#
# Optional sections: responsibilities, nice to have (preferred: also works).
# Folders named _something, example, or template never appear on the site.
